- Four residual blocks × 32 channels; leaky-ReLU value head; FP32 CUDA.
- **Batch 2**, six feature workers, four Torch threads; LR .01, SGD momentum .9,
  weight decay .0001, gradient clipping 5. This retains cg6's batch size, rather
  than silently adopting the separate augmentation screen's batch 32.

- Size 9 only; size weights `9:1,13:0,19:0`; score loss weight 1, ownership .25.

## Ratings and publication

Every candidate is saved to `artifacts/models/cg7/rNNNN/`. On multiples of five,
the launcher invokes the standalone shared evaluator before the next generation:

```sh
python -m continugo_train.rate_saved --resume --include-family cg7 --family-evaluation-every 5
```

It preserves the existing champion and historical results, applies cadence five
to cg7 only, and skips rating rounds 1–4, 6–9, etc. Existing protocol: 7 wins in a
10-game screen permits 30 more games; 28/40 promotes the evaluation champion.
Post-promotion random/history calibration remains the evaluator's responsibility.
Neural ratings use the shared evaluator's frozen 128-simulation budget. A completed
challenge is checked before proceeding; completed evaluations are not repeated on
resume. Shared evaluation-champion replacement is **not accepted-model publication**
and does not change the training actor. No accepted model is automatically published.
